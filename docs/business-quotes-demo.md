# 法人向け概算見積デモ

店舗固有のカスタマイズ。通常購入・決済・在庫引当は変更しません。

## 起動

1. `.env` に `ECCUBE_BUSINESS_QUOTES=1` を設定（未設定時は無効）。
2. `php bin/console cache:clear`
3. `php bin/console doctrine:schema:update --dump-sql` で差分を確認し、`--force` で見積テーブルを追加。
4. `php bin/console cache:warmup`
5. `/business/quote` を開く。管理画面は `/{管理画面パス}/business/quotes`。

無効化は `ECCUBE_BUSINESS_QUOTES=0` に戻しキャッシュを再生成。保存済み見積は削除されません。

## 仕様と制限

- 1見積につき1商品規格、数量1〜10,000。フォームには公開中の商品規格を最大100件表示。
- 同一規格10個以上5%、50個以上10%、100個以上15%引き。デモ用固定条件。
- 税抜商品合計に割引を適用。割引額の円未満は切り捨て。消費税は既存の税設定を使用。
- 数量と商品IDだけを受け取りサーバーで再計算。クライアントの金額は信用しない。
- 価格、宛名、発行元、税額、有効期限は発行時点で保存。後日の価格変更は反映しない。
- PDFは既存の日本語PDFエンジンを利用。概算見積、送料別途、有効期限30日を記載。
- 顧客側の閲覧・PDFは作成したセッション限定（直近100件）。セッション消失後は管理者から再取得。
- 管理者ページは既存admin firewallで保護。CSRF付きフォーム、入力長制限、直後の重複送信抑制あり。
- メール送信、注文確定、在庫確保、配送計算、正式な見積承認は行わない。
- 公開運用前にはIP単位のレート制限、保持期間、正式な発行元情報、税・送料条件の業務確認を行うこと。
